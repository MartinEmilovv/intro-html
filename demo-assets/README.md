# Demo assets

**Primer Logistics** is a made-up company for demos (it matches the "Спедиция Пример ООД"
sample data). Its logo is original and not based on any real company.

| File | Use |
|---|---|
| `primer-logistics-icon.png` | Square icon (512×512), for `LOGO_URL` in the sidebar |
| `primer-logistics-wordmark.png` | Icon with the name (760×320), for slides and emails |
| `logo-icon.svg`, `logo-wordmark.svg` | Editable sources |
| `render.js` | Re-renders the PNGs: `node render.js` (needs Playwright) |

Colors: navy `#12355b` (use as `BRAND_COLOR`), orange `#f5a524`, slate `#5b7088`.
