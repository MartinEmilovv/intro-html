Inbox: an add-in

Installs into Outlook or Gmail like any add-in. It reads incoming requests and shows the sidebar next to the email. Replies go to Drafts.

History: their own data

Past sold prices and carrier prices are imported once from their TMS or Excel files, then kept up to date from every new order.

TMS: an integration

Uses the TMS's API or import file where one exists. Where none exists, the order can be exported to copy in, until an integration is built.
